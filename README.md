# AI Dev Live 2026 — HTML-книга по первому дню

Неофициальное обучающее издание на русском языке по записи 11 ноября 2026 года: https://youtu.be/PkTZHEngE3Q

## Как открыть

1. Распакуйте ZIP-архив.
2. Откройте `index.html` в браузере.
3. Не переносите отдельные HTML-файлы без папки `assets`: она содержит стили, JavaScript и данные навигации.

**Локально и без сервера** работают: оглавление, главы, глоссарий, поиск на главной странице, поиск по словарю, переключение темы, кнопки копирования и отметки прочитанных глав (при поддержке localStorage). Переходы к видеозаписи и миниатюра на главной странице требуют интернета.

## Как разместить на GitHub Pages

Создайте репозиторий, загрузите в его корень **содержимое** папки `ai_dev_live_book` (файл `index.html`, страницы глав и папку `assets`) и включите Pages с веткой `main` / корнем `/`. После публикации главная страница откроется по адресу GitHub Pages вашего репозитория.

- `05_career.html` — собеседования и грейды (Екатерина Фирсова).
- `06_quality.html` — гарантии качества (Константин Доронин).
- `07_sdd.html` — спецификации и brownfield (Егор Толстой).
