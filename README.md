# AI Dev Live 2026 · интерактивная HTML-книга

Полное редакторское издание по конференции 11–12 ноября 2026 года.

## Быстрый запуск

1. Распакуйте архив с сохранением структуры каталогов.
2. Откройте `index.html` в браузере. Для GitHub Pages загрузите всё содержимое папки `ai_dev_live_book` в корень репозитория и включите Pages.
3. Используйте поиск по главам, оглавления, таймкоды и переключатель анимации.

## Содержимое

- 18 отдельных глав (`01_...`—`09_...` и `d2_10_...`—`d2_18_...`).
- `10_glossary.html` — глоссарий, дополненный понятиями второго дня.
- `11_playbook.html` — практические чек-листы.
- `comparison.html` — сравнение идей двух дней.
- 3 тематические анимированные SVG-схемы в каждой из 18 глав (+ схемы оглавления и дополнений).
- Вся стилизация и анимация локальные: `assets/style.css`, `assets/app.js`, `assets/catalog.js`. Нет зависимости от CDN.
- Уважение `prefers-reduced-motion` и кнопка включения/выключения движения в шапке.
